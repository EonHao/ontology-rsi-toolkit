# ontology-rsi-toolkit

A [PenguinHarness](https://github.com/Prism-Shadow/penguin-harness) RSI toolkit. It keeps a typed domain ontology for an agent and refines it from the agent's own Traces. The ontology covers entity types, relations, state lifecycles, source precedence, action contracts and constraints, and every element cites verbatim evidence from a Trace.

Status: design under review for [penguin-harness-community#37](https://github.com/Prism-Shadow/penguin-harness-community/issues/37). No code yet.
