# ontology-rsi-toolkit

A [PenguinHarness](https://github.com/Prism-Shadow/penguin-harness) RSI toolkit. It keeps a typed domain ontology for an agent and refines it from the agent's own Traces. The ontology covers entity types, relations, state lifecycles, source precedence, action contracts and constraints, and every element cites verbatim evidence from a Trace.

Status: phase 1 under development for [penguin-harness-community#37](https://github.com/Prism-Shadow/penguin-harness-community/issues/37). Not yet measured on a benchmark.

- Design: [DESIGN.md](DESIGN.md) · [中文](DESIGN.zh.md)

## Layout

| Path | What |
| --- | --- |
| `src/index.ts` | The plugin's card and Skill contribution; `pnpm build` writes `ifaces.json`. |
| `skills/ontology-rsi-toolkit/SKILL.md` | Organizer entry point: prepare, train, test, report. |
| `skills/ontology-rsi-toolkit/references/` | Benchmark resolution, initialization, the in-container training loop, the Ontologist's edit language, and the shared `evaluation.md`. |
| `skills/ontology-rsi-toolkit/scripts/onto.mjs` | The deterministic half. It publishes structure on a verbatim quote and policy on an experiment: `judge`, `localize`, `gaps` and `experiment` turn the training judge into an instrument; `apply`, `validate`, `render` and `export` manage the slot. Node built-ins only. |
| `test/` | Tests of `onto.mjs`: `pnpm test`. |

## Build and install

`ifaces.json` is generated by the harness's own generator, so the build needs a checkout of [penguin-harness](https://github.com/Prism-Shadow/penguin-harness) with its dependencies installed:

```bash
pnpm install
PENGUIN_HARNESS=/path/to/penguin-harness pnpm build   # default: ../penguin-harness
pnpm test
penguin plugin install .                              # into the running server's library
```

The card has category `rsi`, so the toolkit appears under **Method** in the Evaluation Center's Optimize tab once installed.
